    LOCAL HARNESS · FLEXIBLE MODELS

    YOUR AGENT WORKSPACE

    Model settings

    Choose a provider and model for each role, or add your own API connection. These choices apply to your next run; token budgets come from the local server configuration.

    API keys and connections

    Paste your API key below and apply settings. Keys are saved in this app's local .env file, excluded from Git, and never displayed again. Leave a field blank to keep its current key.

    Add an API provider

    Use a hosted API or your own inference endpoint. Add the connection, then enter its key above and select its model for each role.

    Your own model server

    Upload your model weights and supporting files to your own GPU server and start its inference service. Use Add an API provider to connect its endpoint, then select its provider and served model below. Server setup and model uploads are managed by you.
